DemandIQ — Grocery Demand Planning Website

This version keeps the website name DemandIQ and focuses only on groceries.
Navigation buttons open separate full-page-style views within the website (single-page app behavior).
Included views: Home, Groceries, Demand Planner, How It Works, Our Impact, Login.

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern browser.

The login is a front-end demo only. It does not verify real accounts or save data to a server.
The demand planner uses a simple formula and sample grocery data, not a trained AI model or live store data.
